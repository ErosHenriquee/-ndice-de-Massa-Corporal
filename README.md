# 📊 Cálculo de Índice de Massa Corporal (IMC)

Este repositório contém a resolução de um Exercício de Python, cujo objetivo é calcular o IMC de uma pessoa e classificar seu status de peso.

## 📝 Enunciado do Exercício
Desenvolva uma lógica que leia o peso e a altura de uma pessoa, calcule seu Índice de Massa Corporal (IMC) e mostre seu status, de acordo com a tabela abaixo:

*   **IMC abaixo de 18,5:** Abaixo do Peso
*   **Entre 18,5 e 25:** Peso Ideal
*   **25 até 30:** Sobrepeso
*   **30 até 40:** Obesidade
*   **Acima de 40:** Obesidade Mórbida

## 🧮 Como funciona o cálculo?
A fórmula matemática utilizada para calcular o IMC é:
\[IMC = \frac{peso}{altura^2}\]
